# IDE integrations

IDE integrations support discovery, official marketplace installation, version display,
connection guidance, and deep links where vendors document them. They cannot enter automatic
routing without an independent machine interface.

Roo Code and Windsurf are currently IDE-only. Cline has both an IDE integration and a reviewed
preview CLI. Cursor has a documented `cursor-agent` headless interface, so it is catalogued as a
terminal connector while still awaiting adapter and real-binary evidence.
