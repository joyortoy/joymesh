# Connector security

The browser selects connector IDs and reviewed method IDs, never raw commands. Nodes resolve
platform, prerequisites, official source, executable ownership, and exact argv. Plans are
hash-bound, expire, and require explicit approval.

Executors must use argument-vector process creation, filtered environments, bounded workspaces,
strict timeouts, process-group cancellation, and output redaction. They must not modify global
Git configuration, delete provider credentials, silently change billing routes, or expose an
arbitrary execution endpoint.

Raw harness output is local diagnostic material only when explicitly enabled. Normalized cloud
events are redacted before transmission.
