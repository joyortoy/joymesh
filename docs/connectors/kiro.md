# Kiro CLI

- Platforms: macOS, Linux, native Windows 11; executable: `kiro-cli`; official script is
  digest-gated.
- Authentication: browser login or `KIRO_API_KEY` for eligible subscriptions.
- Execution: documented non-interactive chat with tool trust and session resume.
- JoyMesh maturity: authenticatable and experimental while Kiro 3.0 is early access.
- Official source reviewed 2026-07-29: <https://kiro.dev/docs/cli/reference/cli-commands/>.
