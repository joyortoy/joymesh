# Windsurf

- Platforms: macOS, Linux, Windows editor application.
- Authentication and connection are handled through the editor.
- Execution: IDE-only; an independent remotely executable agent CLI was not verified.
- JoyMesh maturity: discoverable and not routable.
- Official source reviewed 2026-07-29: <https://docs.windsurf.com/windsurf/getting-started>.
