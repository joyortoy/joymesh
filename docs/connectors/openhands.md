# OpenHands CLI

- Platforms: macOS, Linux, and Windows through WSL; executable: `openhands`; recommended `uv tool`.
- Authentication: OpenHands Cloud login or configured LLM provider; local endpoints are supported.
- Execution: headless JSONL, session resume, and experimental ACP.
- JoyMesh maturity: authenticatable; isolated runtime and binary certification pending.
- Official source reviewed 2026-07-29: <https://docs.openhands.dev/openhands/usage/cli/command-reference>.
