# OpenCode

- Platforms: macOS, Linux, Windows; executable: `opencode`; official npm and Homebrew methods.
- Authentication: OpenCode Zen or direct/local provider configuration.
- Execution: JSON events through `opencode run`; provider billing remains explicit.
- JoyMesh maturity: adapter-conformant, not real-binary certified.
- Official source reviewed 2026-07-29: <https://opencode.ai/docs/cli/>.
