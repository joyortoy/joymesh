# Provider modes

Providers fund or route harness execution; they are not harness cards. FireConnect, Fireworks,
OpenRouter, LiteLLM, Ollama, LM Studio, vLLM, OpenAI-compatible endpoints, major cloud model
services, and direct vendor APIs belong in provider or route records.

Each mode records funding source, authentication method, model-discovery support,
usage-reporting support, and whether billing is separate when known. Unknown billing remains
unknown and requires a conservative approval policy.
