# Warp Oz CLI

- Platforms: macOS, Linux, and Windows through the Warp bundle; executable: `oz`.
- Authentication: `oz login` or `WARP_API_KEY`; `oz whoami --output-format json` verifies identity.
- Execution: local `oz agent run` or cloud runs; these remain distinct route types.
- JoyMesh maturity: authenticatable; output conformance and binary certification pending.
- Official source reviewed 2026-07-29: <https://docs.warp.dev/reference/cli>.
