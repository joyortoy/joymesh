- Authentication: ChatGPT browser login or OpenAI API key; these funding modes are separate.
- Execution: structured JSONL `codex exec`; sessions and resume are documented.

- Official source reviewed 2026-07-29: <https://developers.openai.com/codex/cli/reference/>.
