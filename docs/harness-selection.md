# Harness selection

No harness is selected by default. Each card displays description, recommended
uses, setup difficulty, installation and authentication methods, funding modes,
automatic-install support, certification cost, paid-inference risk, platform
support, FireConnect compatibility, and known limitations.

Codex, OpenCode, and the fake harness are the supported onboarding targets.
Other catalogue entries may remain visible as unsupported. Visibility is not a
support claim: an adapter is supported only after the applicable shared
conformance suite passes.

Presets may group selections, but applying one is an explicit user action and
the resulting individual choices remain editable.
